## 1. helper 落点

**新建 `orca/iface/in_session/_tape_probe.py`**（iface 同包新模块，spec §5.1 指定）：

- `TERMINAL_EVENT_TYPES: frozenset[str] = {"workflow_completed", "workflow_failed", "workflow_cancelled"}`
- `class TapeParseError(Exception)`：坏 JSON / partial 残行（fail loud I5）。
- `class TapeContradictionError(Exception)`：含 `types: frozenset[str]`（去重后命中的不同终态类型集合）+ `last_seq: int`（扫描命中的最末终态事件 seq；无终态时为 0，但此 exception 仅在 ≥2 类时抛，故 last_seq > 0）。
- `def scan_terminal(tape_path: Path) -> str | None`：
  - 单遍读文件，逐行 `json.loads`。
  - `json.JSONDecodeError` → 立即 `raise TapeParseError(path, lineno)`（fail loud 中间残行 / 末尾 partial 都不放过）。
  - 行解析成 dict 成功但 `Event(**obj)` 校验失败（pydantic） → `logger.warning` + `continue`（schema 演化软失败，不阻塞）。
  - 命中 `type ∈ TERMINAL_EVENT_TYPES`：`terminal_count += 1`；`terminal_types_seen.add(type)`；`last_terminal_type = type`；`last_seq = obj.get("seq", 0)`。
  - 扫完判定（顺序）：
    1. `len(terminal_types_seen) > 1` → `raise TapeContradictionError(types=..., last_seq=last_seq)`。
    2. `terminal_count >= 2 AND len(terminal_types_seen) == 1` → `logger.warning("[AUDIT] duplicate-terminal types=%s count=%d", ...)`，返 `last_terminal_type`（让 stop 走分支 2 短路 exit 0）。
    3. 否则返 `last_terminal_type`（可能为 None）。
- **依赖单向**：仅 import `orca.schema.Event`（合法 events→iface 方向）+ 标准库 `json`/`logging`。**禁止 import `orca/iface/web/`**。

## 2. `cli.py::stop` 改动（spec §4.1 控制流骨架 B-5）

替换 `cli.py:1766-1785` flock 之后的整段为：

```
acquired = _try_acquire_flock(tape_path)
if acquired is None:
    _echo_busy_reply()
    return
fd, _ = acquired
try:
    try:
        last_term = scan_terminal(tape_path)        # 纯只读 scan，不开 bus
    except TapeContradictionError as e:
        # 分支 0：fail loud I5
        logger.warning("[AUDIT] tape-contradiction path=%s types=%s last_seq=%d", tape_path, e.types, e.last_seq)
        typer.echo(f"tape 终态矛盾：{tape_path} 含 {sorted(e.types)}（last_seq={e.last_seq}），请手动核查（doctor 暂不修复 tape 内容）", err=True)
        raise typer.Exit(1)
    except TapeParseError as e:
        # 分支 1：fail loud I5
        typer.echo(f"tape 损坏：{tape_path} 第 {e.lineno} 行非合法 JSON，请手动核查（doctor 暂不修复 tape 内容）", err=True)
        raise typer.Exit(1)
    if last_term == "workflow_cancelled":
        # 分支 2：already-cancelled 短路（含 B-1 同类重复 warn 后短路）
        typer.echo(json.dumps({"run_id": rid, "ok": True, "done": True, "note": "already-cancelled", "status": "cancelled"}))
        return
    if last_term in ("workflow_completed", "workflow_failed"):
        # 分支 3：already-terminal 自然终态
        typer.echo(json.dumps({"run_id": rid, "ok": False, "done": True, "note": "already-terminal", "status": last_term}))
        return
    # 分支 4：无终态 → emit
    tape_obj = Tape(tape_path, run_id=rid, resume=True)
    bus = EventBus(tape_obj)
    try:
        asyncio.run(bus.emit("workflow_cancelled", {"reason": "user_stop"}))
    finally:
        # 内层 finally：仅 bus.close()，fd/marker 由外层 finally 统一释放
        # （rev4 N1 / round-4 E3 fd 双释放 hazard）
        bus.close()
    typer.echo(json.dumps({"run_id": rid, "ok": True, "done": True}))
finally:
    # 外层 finally 兜所有分支
    _release_flock(fd)
    clear_marker(mpath)
```

关键：
- `Tape(resume=True)` + `EventBus` **仅分支 4 内**实例化（B-5；零 bus 对象于分支 0/1/2/3）。
- 内层 finally 仅 `bus.close()`，`_release_flock` + `clear_marker` 外层兜底（fd 双释放 hazard 修复）。
- `no-tape` 分支（行 1760-1764）保持现行，外层不持 fd（早 return 前）。

## 3. `cli.py::_find_active_run_for_wf` 改动（spec §4.2）

替换 `cli.py:855-874`：

```
def _find_active_run_for_wf(rundir, wf_name):
    """...docstring 改：tape 终态判活跃，marker 仅索引候选..."""
    if not rundir.exists():
        return None
    candidate_markers = sorted(rundir.glob("orca-*.json"))
    if len(candidate_markers) > 5:
        logger.warning("[AUDIT] candidate-marker-flood count=%d wf=%s", len(candidate_markers), wf_name)
    for mp in candidate_markers:
        marker = read_marker(mp)
        if marker is None:
            continue
        tape_path = Path(rundir) / f"{marker.run_id}.jsonl"
        # step 2: wf_name 过滤先于终态扫描
        if _read_workflow_name(tape_path) != wf_name:
            continue
        # step 3: per-candidate scan（异常隔离，禁包循环外）
        try:
            term = scan_terminal(tape_path)
        except TapeContradictionError:
            logger.warning("[AUDIT] candidate-tape-contradiction run=%s", marker.run_id)
            continue
        except TapeParseError:
            logger.warning("[AUDIT] candidate-tape-corrupted run=%s", marker.run_id)
            continue
        if term is None:
            return marker.run_id            # 真·活跃
        # 已终态（含 duplicate-terminal warn 已在 reader 内打出）→ 跳过
    return None
```

- `_read_workflow_name` 保持现行（head 100 行 scan）；spec 显式登记「头部坏 tape 走 wf_name 过滤静默跳过」—— `_read_workflow_name` 头部坏 → None → 与 wf_name 不等 → continue（与正文坏 tape 的 `[AUDIT] candidate-tape-corrupted` warn 分级，符合 round-4 E4）。
- `_find_active_run_for_wf` 不 raise（活动性查询本职；raise 仅留给 stop）。
