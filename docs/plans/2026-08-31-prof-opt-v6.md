## 1. 目标与范围

**目标**：把 prof-opt 从 v5（≤3 提案 + stop-at-k 粗训 + 独立 full-train + 串行门禁）重写为 v6（每轮 1 变体收敛环 + probe 占卡启动即放行 + detached watchdog 流式早停 + top-10/帕累托推送），并新增 web 分析文档面板（chart 清单 + 点开拉取渲染）。

**非目标**：
- 引擎层 / schema / exec / iface 编排改动（全部落在 workflow 脚本层 + web 只读端点）。
- 真机 NPU/GPU E2E、真实 mfu 评测（归用户，v6 §16）。
- 跨 run 对比视图、文档编辑/写回（web SPEC §0）。

**规模标注**：large（9 个脚本改 + 3 脚本 + 1 sh 新增、2 个节点级 agent.md 重写、1 节点删除、4 子代理 prompt 改、workflow.yaml 结构变更、前后端各一组新文件、测试两个文件级新增 + 一个清理）。
