## 改动清单（surgical）

### 1. `orca/iface/web/run_manager.py`

#### 1.1 N1 — `_summary_from_tape` 内层 except 补 warn（fail loud）
- 位置：`_summary_from_tape`（约 1629-1632）的内层 `except Exception: return None`。
- 改：补 `logger.warning("tape 概览扫描失败 %s", tape_path, exc_info=True)` 再返 None。
- 外层 §4.1 的 except warn 保留（语义「discovery skip」）。

#### 1.2 E-1 — `discover_runs` legacy 分支改走 `_summary_from_tape`
- 位置：`discover_runs` legacy 分支（约 1431-1454）。
- 改：
  - 引入 `seen_ids: set[str] = set()` 跨三分支共享 dedup。
  - attached 分支：skip-if-in-self._runs（保留）+ skip-if-in-seen_ids + 显式 add。
  - in-memory 分支：skip-if-in-seen_ids（防御）+ 显式 add；保留无条件 overwrite summaries / new_index（in-memory live 权威）。
  - legacy 分支：
    - tape_path 相对路径或不存在 → warn + skip（fail loud，AC4）。
    - 调 `_summary_from_tape(tape_path, project_id=None, project_name="Legacy", source="legacy")`。
    - except → warn + skip（外层语义「discovery skip」）。
    - None → skip（0 有效事件 / 空 tape）。
    - **E5 / AC10**：`if summary.run_id != lm.run_id: logger.warning("legacy meta run_id mismatch: meta=%s tape_stem=%s (using tape)", lm.run_id, summary.run_id)`；以 tape_path.stem 为权威 run_id。
    - skip-if-in-seen_ids + 显式 add。
    - new_index 仅在未占时写入（最低优先级）。
- workflow_name 走 `_summary_from_tape` 内部退化（`_topology_workflow_name_from_tape(tape_path) or tape_path.stem`，1619 已存在），不传 yaml_path.stem hint（E11 / DRY）。

#### 1.3 E-2 — handle.status hint 语义文档化（方向 A，不动代码）
- 在 `_meta_from_handle`、`list_runs`、`discover_runs` 三个公共方法 docstring 命中关键词集 {hint, tape, 权威, transient}。
- 在 `RunMeta.status` / `RunSummary.status` 字段行注释 `# hint: 权威在 tape`。
- 显式说明 in-memory 分支 status/event_count 取 handle 字段属 C1 perf 豁免，progress/cost/elapsed 仍走 replay_state。

#### 1.4 AC8b — `_meta_from_handle` replay 失败降级 warn 加 `replay-degraded` 标记
- 当前 1261 行 warn 缺稳定 grep 锚点；补：消息含 `run_id` + `replay-degraded`。
- 不改语义（仍 `status = handle.status`，零回归）。
