**abort-all-entries helper**：iterate Map → `ctrl.abort(); clearTimeout(timer); map.delete(...)`。

**fetchWithBackoff helper**（3 次指数退避 1s/2s/4s，含 retry fetch 带 signal，G2/C12；每次 `set({retryCount:n})` 驱动 banner E4）：
- 退避期间 loadStatus 保持 `loading`（BLOCKER-3）
- 任一 attempt 成功 → return parsed array

**关键 loader 三处**（`loadRun` / `loadRunWithMeta` / `loadFull`）+ `loadEarlierChunk`：

```
async loadRunWithMeta(runId):
  // 入口：abort-all-entries（E9：moduleEpoch++ BEFORE iterate-abort）+ reset retryCount
  moduleEpoch++; const myEpoch = moduleEpoch;
  abortAllEntries();
  const entry = { abort: new AbortController(), timer: null, epoch: myEpoch };
  inflight.set(runId, entry);
  set({ loadStatus:"loading", loadError:null, retryCount:0, historyLoadError:false });

  try {
    const meta = await fetchMeta({signal})  // silent fallback on failure (INV-1 qualifier)
    if (meta?.huge) {
      const tail = await fetchEvents(url + "?tail=500", {signal})  // 退避 3 次
      const patch = { huge:true, hugeFullyLoaded:false, serverOverview:meta.overview, writable:meta.writable, oldestSeqInWindow, newestSeqInWindow }
      commitAtomic(runId, myEpoch, tail, patch, "loaded")  // 单 set 同时写所有 + loadStatus
    } else {
      set({ huge:false, hugeFullyLoaded:true, serverOverview:null, writable: meta?.writable ?? true })
      await loadRunWithEpoch(runId, myEpoch, entry)  // 内部走 events 退避 + commit
    }
  } catch (err) {
    setError(runId, myEpoch, err)  // 写 loadError + loadStatus=error
  } finally {
    if (inflight.get(runId)?.epoch === myEpoch) inflight.delete(runId)
  }
```

- 写时双重校验：`if (get().activeRunId === runId && moduleEpoch === myEpoch)` 在 `set(...)` 调用前判断；不一致则丢弃。注意 `activeRunId === runId` 校验对切到别的 run 有效，对 A→B→A 同 runId 靠 moduleEpoch 区分（N2）。
- 非 array JSON（`!Array.isArray(json)`）→ throw `LoadError{kind:"parse"}`（G7）。
- `resp.json()` throw 由 try/catch 归到 parse 类。

**loadEarlierChunk**（免退避，banner-only C6；写时双重校验 C2；节流同窗口只 set 一次）：
- 失败 → `set({historyLoadError:true})`（节流：若已 true 则不重复 set）
- 成功 → `set({historyLoadError:false})` 清
- 写入前校验 `activeRunId + moduleEpoch`，不一致丢弃

**processEvent**（INV-7 + seenSeqs O(1) E6）：
```
processEvent(event):
  set((state) => {
    // INV-7 拒收：loadStatus !== "loaded" → drop + warn-once
    if (state.loadStatus !== "loaded") {
      const key = `${state.activeRunId ?? "<null>"}::${event.seq}`
      if (!droppedSeqs.has(key)) {
        droppedSeqs.add(key); console.warn(`[orca] INV-7 drop seq=${event.seq} loadStatus=${state.loadStatus}`)
      }
      return
    }
    if (state.seenSeqs.has(event.seq)) return  // O(1)
    // ... 既有 in-order 增量 / out-of-order refold
    state.seenSeqs.add(event.seq)  // 仅 in-order 分支显式 add；out-of-order 由 refold 末尾重建
  })
```

**unloadRun**：abort-all + Map.delete + 复位 `loadStatus="idle" / loadError=null / retryCount=0 / historyLoadError=false / seenSeqs=new Set()` + 清 droppedSeqs + untitledWarned Set（E6/MINOR-5）。

**public loadFromEvents 不翻 loadStatus**（E7）：保持现状（set events + refold），**不**写 loadStatus；这是 triggerResumeFallback 专用路径。

**dev-mode `__foldTwiceForInvariantCheck(event)`**（B3）：apply 两次比较派生快照，任何变化 → `console.warn`；prod (`!import.meta.env.DEV`) no-op。

**foreach_item_completed** silent skip → `console.warn` + 保留原值（M4）。

**注释/docstring 修正**（M22/E5）：L36 改成「events 数组（升序）+ seenSeqs Set 索引」；L100 docstring 删除「失败 fail loud」或对齐实现；L128 PRECONDITION 注释加「dev-mode 自检 helper 验证」。

## Step 2 — use-websocket.ts 改造（defer-RESUME）

listener 在 useEffect 顶层注册一次（BLOCKER-2）：
```
useEffect(() => {
  ...
  let resumeSent = false;  // per-socket closure（MAJOR-2）
  const trySendResume = (sock: WebSocket | null) => {
    if (!sock || sock.readyState !== READY_OPEN || resumeSent) return
    const since = useWorkflowStore.getState().lastSeqSeen
    sock.send(JSON.stringify({type:"resume", run_id:runId, since}))
    resumeSent = true
  }

  // listener: 顶层注册一次，diff loadStatus → loaded 时 fire sendResume + one-shot 自清
  const unsub = useWorkflowStore.subscribe((curr, prev) => {
    if (prev.loadStatus !== curr.loadStatus && curr.loadStatus === "loaded") {
      trySendResume(socket)  // 读 closure 内当前 socket
      unsub()  // one-shot 自清
    }
  })

  open();  // 内部 onopen 改：

  socket.onopen = () => {
    ...
    // loadStatus 优先于 wasReconnect（F1）
    const st = useWorkflowStore.getState().loadStatus
    if (st === "loaded" || st === "error") {
      trySendResume(socket!)  // 首帧 sendResume
      // reconnect 路径 + server-restart 韧性：次帧 sendSubscribe
      if (wasReconnect) sendSubscribe(socket!)
      armResumeWatchdog()
    } else if (wasReconnect) {
      // loading/idle + reconnect：不双发，仍走 listener 路径（仅 listener 后续发 sendResume）
      // 不发 sendSubscribe（lazy-mount 不需要——loading 期 server 一般未重启）
    }
    // initial mount + loading/idle：等 listener 回调（什么都不做）
  }

  return () => {
    closedByUs = true
    ...
    unsub()  // cleanup
  }
}, [runId, processEvent])
```

**保留**：`sendSubscribe` helper、`sendResume` 改为 trySendResume（含 resumeSent dedup）、`triggerResumeFallback`（不改 loadStatus，C10）、watchdog、reconnect 退避。

注：`useWorkflowStore.subscribe(listener)` zustand 默认 signature 是 `(listener, opts?) => unsub`，listener 收到 `(state, prevState)`（zustand v5 默认全 state listener）。需 `subscribeWithSelector` 才支持 selector，**不引 middleware**（A1）——用全 state listener 内部 diff。
