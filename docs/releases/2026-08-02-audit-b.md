# Release Note —— SPEC B：resume / 重放幂等裂缝修复

> **日期**：2026-08-03
> **SPEC**：[`docs/specs/2026-08-02-audit-b.md`](../specs/2026-08-02-audit-b.md)（r4 conditional-pass）
> **分支**：`in-session-unified-backend`
> **实施顺序**：B2 → B1 → B3 → MINOR（B1 skipped-window fallback 依赖 B2 形状）

## 改动概览

修复 SPEC B 三条 resume / 重放幂等裂缝 + MINOR tape 遍历合并。核心是让「单 tape 重放
得到同一状态」铁律在 resume 路径下成立：

1. **B2**（reducer 持久层）：`node_skipped` reducer 补 `context[N]=None`（raw，R1 形状）；
   live skip 写 `outputs_acc[N]={"output":None}`（去 `"skipped":True`）。消除 live/resume
   视图发散（I-REPLAY-3）。
2. **B1**（resume 起点）：`from_tape` 判据改为「信任 current_node 除非 status∈{done,skipped}」，
   fallback 走 progressed 序列推断（NEW-1 双终态）。覆盖 `[node_completed(A),route_taken)`
   与 `[node_skipped(A),route_taken)` 两窗口。新建 `replay_for_resume(tape)` 单 pass 产出
   `(state, inputs, last_progressed)`。
3. **B3**（删死字段）：删 `RunState.usage` 归集字段（reducer 永不写），保留 `UsageSummary`
   类（projections.node_usage 用）。run_manager 改读 projections（E1 修 `cost`→`cost_usd`
   typo，被 no-op reducer 掩盖恒返 0.0 的潜伏 bug 一并消除）。
4. **MINOR**（4→2）：`from_tape` tape 全量遍历从 4 次（corrupt + replay_state +
   _find_last_done_node_name + _inputs_from_tape）降为 2 次（corrupt + replay_for_resume
   单 pass）。删 `_inputs_from_tape` wrapper + `_find_last_done_node_name` helper（死代码）。
