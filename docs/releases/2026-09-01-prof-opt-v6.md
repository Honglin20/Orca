## 概要

prof-opt 从 v5（≤3 提案小步迭代 + stop-at-k 粗训 + 独立 full-train + 串行门禁）重写为 v6：**每轮 1 个变体收敛到目标**、probe 认卡后启动即放行、detached watchdog 流式早停自动评测、npu/cuda 设备后端抽象；base 恒为基线永不晋升。Web 侧新增分析文档只读面板。8 节点 → 7 节点（po_full_train 退役）。

## 机制变更（A 线，commit `0653a47` → `339ab8e`）

- **P0 数据契约与共享脚本**（`0653a47`）：`resolve_train_device.sh`（env → npu-smi → nvidia-smi/torch.cuda 四级解析，fail loud）、`device_alloc.py`（O_EXCL 占卡账本 + claim/adopt 锁主生命周期 + pid 死亡回收）、`ledger_aggregate.py` + experiment_ledger 分片化（每变体独占 `ledger_entry.json`，共享账本为确定性聚合派生物——多 watchdog 并行不丢数据）、round_state `mode` 退役 / gate_decide 三分支决策序 / verdict `promote` 退役 / history `append_terminal` / latency recheck 统一判定。
- **P1 propose 单变体收敛环**（`bf9ba4f`）：每轮恰 1 提案（准入 predicted makespan ≤ target）；软对齐三件套（business_logic / information_analysis 变体模式 + conformance.md，口径 = 主要内容对得上、讲得通）；修复内环 ≤5 次（repair_directive = 最新 mfu 报告全文，repair_trace 脚本兜底计数）；rules 增量刷新（`.rules_pending` 标记消费制）。
- **P2 probe 资源分配 + 启动即放行**（`88ee18a`）：verdict 达线为放行硬前提；无卡 park 等待（阻塞不 emit）；liveness 四条件（pid/cmdline/train.log/epoch1 指标可解析）；baseline 链 claim→render `--set device`→finalizer 释放；`check_probe_emit` v6 重写（mode_state 悬空清零）。
- **P3 watchdog 流式早停**（`594fb6d`）：`watch_variant.sh` detached 真身——逐 epoch 与基线同深度 compare（warmup `ceil(0.1×E)` 不判），连续 10 超预算杀进程组（归属校验失败拒杀 FATAL）；自然完成走 finalizer eval 链 + `final-budget` 回填；终态四件套（聚合 ledger + 释放锁 + `append_terminal` + `.rules_pending`）；幂等重入三态；baseline 锚点 bounded-wait（`baseline_anchor_unavailable` 不无限持卡）。
- **P4 前端推送**（`1bfcd49`）：top-10 曲线（在飞优先→success→gap 升序，baseline 恒在）+ 全量 pareto（x 相对降幅 %、状态着色、y=null 占位）+ `prof-opt/docs` 文档清单 table（canonical 行 `vid/doc/status/path`，只推 path 不推正文）；dashboard_snapshot 六字段 + 读路径顺带聚合。
- **P5 收口 + 退役 + 回归**（`604b856` `85749e7` `9820c43` `ad06116` `339ab8e`）：workflow.yaml 8→7 节点、gate routes 改 report/loop+catch-all、output_schema 更新；po_report 多训练收割（无 kill 等待在飞 ≤60s、winner = gap 最优 success、终稿 `--docs` 推送）；退役删除（po_full_train 整目录、advance_round、stop_at_epoch、check_full_train_emit）+ 全仓残留 grep 清零 + 退役测试面清理。
